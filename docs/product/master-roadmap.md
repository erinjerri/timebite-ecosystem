# Master Roadmap

## Release Ladder

- March/April 2027: TimeBite iOS public beta or App Store v1.
- June 2027: partial ecosystem demo.
- July/August 2027: capsule preview, private demo, or soft launch.
- September 2027: polished integrated presentation/pop-up readiness.

September is the integrated readiness gate. It is not the first meaningful release.

## October 2026 - December 2026

Focus: make TimeBite real enough for beta and establish the shared action contract.

- TimeBite iOS: alpha core loop, local persistence, TestFlight checklist.
- Meta: research supported capabilities and define first action invocation route.
- Unity: scope only unless competition deadline demands early work.
- Fashion: select 2-3 hero looks.
- Purse: choose flagship purse and dimensions.
- Charm: choose one flagship character and M5Stack platform.

Release gate: TimeBite TestFlight should start before any experimental integration can slow the app.

## January 2027 - March 2027

Focus: beta learning, February sourcing readiness, first external interface proof.

- TimeBite iOS: beta testing, stabilization, App Store readiness, and public beta/App Store v1 if stable by March.
- Meta/charm: prove at least one external interface can call TimeBite actions.
- Unity: complete bounded demo if useful for VR Start.
- Fashion/purse: tech packs, initial materials, samples/mockups.
- Charm: M5Stack POC, preliminary BOM, enclosure dimensions.

February gate: manufacturer/sourcing readiness packet, not production commitment.

March gate: TimeBite public beta/App Store v1 is protected from Meta, Unity, M5Stack, fashion, and purse dependencies. The first external interface should exist by March if possible, but it cannot hold the app release.

## April 2027 - June 2027

Focus: iterate TimeBite and show the first partial ecosystem preview.

- TimeBite iOS: public beta or App Store v1, then iteration.
- Meta/charm: shared context demo with two interfaces.
- Fashion/purse: sample revisions and costing.
- Hardware: M5Stack evidence review for any smaller bare ESP32/custom PCB path, plus manufacturer conversations.
- June release target: partial ecosystem demo with TimeBite, one external action interface, one hero look sample, purse sample/prototype, and rough M5Stack charm interaction.

May gate: cross-device demo. At least two interfaces should read/write the same TimeBite context.

June gate: credible partial ecosystem scope. Do not expand into a full collection, custom PCB, Unity product, or manufacturing launch.

## July 2027 - September 2027

Focus: summer capsule preview, then integrated public presentation readiness.

- TimeBite: stable demo data and user flows.
- Tagimata: editorial-ready samples and soft-launch assets.
- Charm: reliable demo behavior and production feasibility assessment.
- Ecosystem: one coherent narrative, cost model, and go/no-go decisions.
- July/August release target: private demo, capsule preview, or soft launch.
- September release target: polished integrated presentation/pop-up readiness.

July/August gate: controlled preview quality with 1-2 photographed looks, flagship purse sample, charm demo using shared context, and optional Meta command flow.

September gate: polish, presentation, and pop-up readiness. Mass production remains a separate decision.

## Workstream Limits

- TimeBite: primary effort through public release; integrations stay non-blocking.
- Meta: prove one useful external action flow; do not chase platform breadth.
- Unity: time-box and archive after a credible demo/submission unless strategic evidence changes.
- Charm: one M5Stack ESP32-family platform until evidence supports a smaller bare ESP32/custom PCB path.
- Firmware: embedded C/C++ or Rust; no production MicroPython.
- Fashion: 2-3 hero looks only.
- Purse: one flagship purse and optionally one secondary design.
