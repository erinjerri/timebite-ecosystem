# Milestones

## M0 - Architecture Locked Enough To Build

Target: October/November 2026.

Exit criteria: shared action contract, repo boundaries, canonical entity list, and first demo thesis documented.

## M1 - TimeBite Core Loop Works

Target: November 2026.

Exit criteria: Intent -> Task -> Timer -> Activity -> Reflection works locally.

## M2 - TestFlight Beta

Target: December 2026/January 2027.

Exit criteria: external users can test TimeBite without founder hand-holding. TimeBite includes the core Daily Intent -> task/project/goal -> timer -> Activity Ring -> reflection loop, local persistence confidence, beta-safe privacy/auth posture, and a known App Store readiness checklist.

## M2.5 - TimeBite Public Beta Or App Store V1

Target: March/April 2027.

Exit criteria: TimeBite can be released independently of Meta, Unity, fashion, purse, or charm. The app has a stable core loop, privacy/auth readiness, persistence confidence, and enough polish for real users.

Non-goals: Meta glasses, Unity, M5Stack charm, fashion samples, purse samples, and manufacturing readiness cannot block this release.

## M3 - First External Interface

Target: March 2027.

Exit criteria: Meta or M5Stack successfully invokes shared TimeBite actions. The integration uses the shared action/data contract and does not require changing the TimeBite public release scope.

## M4 - Cross-Device Demo

Target: May 2027.

Exit criteria: at least two interfaces read/write the same TimeBite context.

Example scope: iOS plus Meta, or iOS plus M5Stack charm. This is a demo gate, not a requirement for TimeBite release.

## M4.5 - Summer Partial Ecosystem Demo

Target: June 2027.

Exit criteria: TimeBite is usable by real users; one external interface invokes shared actions; one hero look exists as sample/mockup; one purse sample/prototype exists; the M5Stack charm can demonstrate a rough but compelling interaction.

Non-goals: no full collection, no purse electronics, no custom PCB, no large inventory purchase, no Unity productization.

## M5 - Tagimata Physical Samples

Target: April/May 2027.

Exit criteria: one hero look and one purse physically exist.

## M6 - Interactive Charm Prototype

Target: April/May 2027.

Exit criteria: one M5Stack-powered character demonstrates useful interaction.

## M7 - Manufacturing Readiness

Target: June/July 2027.

Exit criteria: tech packs, BOM, electronics requirements, costing assumptions, and RFQs are ready.

Earlier checkpoint: February 2027 manufacturer/sourcing readiness should cover hero look specs, purse tech pack draft, charm dimensions/BOM assumptions, vendor questions, and sample path decisions. February is for readiness and sourcing conversations, not production commitment.

## M8 - Integrated Editorial/Product Demo

Target: July/August 2027.

Exit criteria: fashion, purse, charm, TimeBite, and optional wearable interaction can be demonstrated coherently as a capsule preview, private demo, or soft launch.

Minimum scope: 1-2 photographed looks, flagship purse sample, charm demo using shared TimeBite context, released or stable TimeBite app, and optional Meta command flow.

## M9 - September 2027 Presentation / Pop-Up Readiness

Target: September 2027.

Exit criteria: minimum viable collection and technology demo are ready for credible public presentation. September should polish the already proven spring/summer ladder into one integrated story, presentation kit, cost model, risk register, and go/no-go decision set.

Non-goals: September is not the first TimeBite release and should not force mass manufacturing unless summer evidence supports it.
