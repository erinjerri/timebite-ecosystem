# February 2027 Manufacturing And Sourcing Gate

February 2027 is a readiness checkpoint for Japan/Asia sourcing and manufacturer discussions.

## Fashion Checklist

- selected hero looks
- technical drawings
- initial patterns/specifications
- fabric/material direction
- initial samples or mockups where possible
- clear questions for sample makers

## Purse Checklist

- chosen flagship design
- dimensions
- material specification
- hardware requirements
- charm attachment specification
- tech pack draft
- planner/phone fit assumptions

## Charm Checklist

- working or partially working M5Stack proof of concept
- physical dimension envelope
- movement specification
- audio requirements
- battery assumptions
- preliminary BOM
- ESP32 questions and evidence threshold
- plush/enclosure requirements

## Does Not Need To Be Ready

- final production collection
- final size run
- final PCB
- certifications
- tooling
- large inventory order
- multi-character electronics
- final packaging
