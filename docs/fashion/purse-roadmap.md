# Tagimata Purse Roadmap

## Scope

Develop one primary flagship purse and optionally one secondary design. Do not develop the entire bag collection initially.

## Flagship Purse Requirements

- premium contemporary aesthetic
- carries phone, TimeBite planner, charm, regular charms, and personal accessories
- VEGEA or other plant-based leather exploration
- possible bamboo or Filipino material references
- Tagimata emblem
- 16-point motif
- durable charm attachment location
- internal organization compatible with planner dimensions
- no electronics in v1 unless overwhelmingly justified

## Optional Secondary Purse

Smaller evening/crossbody design that tests whether the Tagimata language works in a more editorial or dressed-up context.

## Development Stages

Concept -> dimensions -> materials -> hardware -> technical drawings -> tech pack -> prototype/sample -> revision -> final sample -> costing -> MOQ -> manufacturer selection -> production decision.

## February 2027 Target

- chosen flagship design
- dimensions
- material specification
- hardware list
- tech pack draft
- charm attachment spec
- questions for manufacturers about MOQ, lead time, materials, and sample costs
