# Codex Prompt: Tagimata Fashion Repository

You are working in the Tagimata fashion repository. `timebite-ecosystem` is the architectural source of truth for cross-product roadmap and integration boundaries.

## Repository Responsibility

Develop the first coherent Tagimata capsule: apparel, purse/accessory direction, materials, patterns, tech packs, samples, sourcing, and presentation assets.

## Immediate Milestone

February 2027 sourcing/manufacturer readiness.

## Required Interfaces

Coordinate with ecosystem specs only where the physical product touches technology:

- flagship purse dimensions for phone/planner/charm
- charm attachment specification
- 16-point motif usage
- visual relationship to TimeBite/Tagimata demo

## Do Not Build

- Do not design the entire long-term collection first.
- Do not require electronics in every garment or bag.
- Do not define TimeBite software schemas.
- Do not create multiple charm electronics assumptions.

## Implementation Phases

1. Select 2-3 hero looks.
2. Produce sketches/specifications.
3. Define materials and color family.
4. Create patterns or pattern direction.
5. Prepare first samples/mockups.
6. Create purse tech pack and charm attachment spec.
7. Prepare February manufacturer questions.
8. Revise toward editorial samples and production decisions.

## Acceptance Criteria

- 2-3 looks clearly express Tagimata.
- One flagship purse is specified.
- February sourcing packet is actionable.
- Work supports, but does not depend on, unfinished electronics.
- Unrelated files are left untouched.
